API Documentation

Welcome to the official Forza Open API documentation. Use this page to understand our endpoints, response structures, and querying parameters.

Information

This is a consumption-only API — only the HTTP GET method is available on public resources.

No authentication is required to access this API, and all resources are fully open. We utilize robust caching via Redis Upstash to guarantee rapid response times across our globally distributed nodes.

Fair Use Policy

Forza API is free and open to use. Because of this, we ask every developer to abide by our fair use policy. People not complying with the fair use policy will be subjected to rate-limiting or IP bans.

  • Locally cache resources in your own mobile app or web client whenever you request them.
  • Avoid spamming heavy complex filtering endpoints in loops.
  • If you spot data inaccuracies, please contribute via our official GitHub repository.

Pagination & Sorting

Calling any list endpoint without a specific resource ID will return a paginated list of available resources. By default, a list "page" will contain up to 20 resources.

GET https://api.forza-api.com/api/v1/vehicles?page=0&size=20&sort=modelName,desc
Parameter Description
page The page index you want to retrieve. Starts at 0.
size Number of items per page. Default is 20.
sort Field to sort by, followed by a comma and direction (e.g., id,asc or modelName,desc).
