API Documentation

Welcome to the official Forza Open API documentation. Use this page to understand our endpoints, response structures, and querying parameters.

Information

This is a consumption-only API — only the HTTP GET method is available on public resources.

No authentication is required to access this API, and all resources are fully open. We utilize robust caching via Redis Upstash to guarantee rapid response times across our globally distributed nodes.

Fair Use Policy

Forza API is free and open to use. Because of this, we ask every developer to abide by our fair use policy. People not complying with the fair use policy will be subjected to rate-limiting or IP bans.

  • Locally cache resources in your own mobile app or web client whenever you request them.
  • Avoid spamming heavy complex filtering endpoints in loops.
  • If you spot data inaccuracies, please contribute via our official GitHub repository.

Pagination & Sorting

Calling any list endpoint without a specific resource ID will return a paginated list of available resources. By default, a list "page" will contain up to 20 resources.

GET https://api.forza-api.com/api/v1/vehicles?page=0&size=20&sort=modelName,desc

tune Query Parameters

Parameter Type Description
page integer The page index you want to retrieve. Starts at 0.
size integer Number of items per page. Default is 20.
sort string Field to sort by, followed by a comma and direction (e.g., id,asc or modelName,desc).

Vehicles

Vehicles are the core physical entities representing cars from the real world. They contain base attributes like engine type, chassis origin, and default drive types before game-specific tuning is applied.

Get All Vehicles

GET /api/v1/vehicles 
Mengambil data dari server...

tune Query Parameters

Parameter Type Description
manufacturerId integer Filters vehicles by the unique identifier of the manufacturer (e.g., id: 54 for Honda).
manufacturerName string Performs a case-insensitive partial match search on the manufacturer name (e.g., porsche).
startYear integer The minimum production year boundary for the dynamic search range (e.g., 1990).
endYear integer The maximum production year boundary for the dynamic search range (e.g., 2025).
driveType string (enum) Filters vehicles by layout configuration. Valid case-insensitive values: FR, MR, RR.
drivetrain string (enum) Filters vehicles by drive system layout. Valid case-insensitive values: AWD, RWD, FWD.

Get Vehicle by ID

GET /api/v1/vehicles/{id}

tune Path Parameters

Parameter Type Description
id REQUIRED integer Unique identifier of the vehicle (e.g., 28).

Search Vehicles by Model Name

GET /api/v1/vehicles/search/{model_name}

tune Path Parameters

Parameter Type Description
model_nameREQUIRED string Performs a case-insensitive partial match search on the vehicle's model name (e.g., furai).

Game Vehicles Stats

Game-specific vehicle statistics including performance ratings, handling characteristics, and classification data for each vehicle across different Forza titles.

Get All Vehicle Stats

GET /api/v1/vehicle-stats

tune Query Parameters

Parameter Type Description
vehicleid integer Filters statistics by the global real-world vehicle ID (e.g., 12).
vehiclename string Performs a case-insensitive partial match search on the car's model name (e.g., trueno).
manufacturerid integer Filters records by the specific car manufacturer's ID.
manufacturername string Filters by manufacturer name via partial query match (e.g., Ferrari).
divisionid integer Filters by the vehicle division category ID.
divisionname string Filters by division/car group names (e.g., Hypercars).
gameid integer Filters stats isolated to a specific game title (e.g., 2).
rarity string (enum) Filters by in-game acquisition rarity (LEGENDARY).
drivetype string (enum) Filters by engine layout and placement matrix (MR).
performanceclass string (enum) Filters by Performance Index (PI) Tier (S1).

Get Vehicle Stats by ID

GET /api/v1/vehicle-stats/{id}

tune Path Parameters

Parameter Type Description
id REQUIRED integer The unique identifier mapping a specific car's metrics directly to a targeted game instance (e.g., 16).

Festival Playlists

Playlists dictate the live-service dynamic events that rotate weekly in the Horizon series (Summer, Autumn, Winter, Spring).

Get Current Playlist

GET /api/v1/festival-playlist/current

tune Query Parameters

Parameter Type Description
gameId REQUIRED integer Fetches the live active timeline profile filtered strictly by the target game title context (e.g., 6 for Forza Horizon 6).

Get All Playlists

GET /api/v1/festival-playlist

tune Query Parameters

Parameter Type Description
gameId integer Filters playlist history by a specific game title instance ID (e.g., 2).
seriesNumber integer Filters by the chronological live-service series index tracker group (e.g., 32).
season string Filters by specific in-game rotating weather seasons (Summer).

Get Festival Playlist by ID

GET /api/v1/festival-playlist/{id}

tune Path Parameters

Parameter Type Description
id REQUIRED integer The unique identifier of the target historical milestone festival event registry (e.g., 706).
